What is networking?

WHAT: Networking is two or more computers connected so they can share data and resources.

Why it mattersOn its own a computer is an island. Networking lets your laptop reach a website on a server far away, lets an office share one printer, and lets phones message each other. Almost everything digital relies on it.
AnalogyA group of people who want to talk need two things: a way to reach each other (voices, phones) and a shared language with manners so they actually understand each other. A network is exactly this — a connection plus a shared set of rules.

A node is any device on a network — your laptop, phone, printer, and router are all nodes.

The three sizes of network

Networks are grouped by how much area they cover.

TypeCoversAnalogy
LANOne small area — a home, school, officeOne house
MANA city or large campusYour neighbourhood
WANRegions, countries, continentsThe whole country's roads

LAN is cheap and fast because everything is close, but security matters — anyone on it can reach shared files. The internet is the largest WAN in existence.

RememberLAN = house · MAN = neighbourhood · WAN = whole country.

4

How devices agree to talk: protocols

WHAT: A protocol is an established set of rules for how data is transmitted between devices.

AnalogyA protocol is the etiquette of a phone call: say "hello," wait for a reply, take turns, say "bye." Both sides follow the same script, so it works every time. Two devices can be connected and still fail to talk if they don't share the same rules.

Common protocols you'll meet: HTTP/HTTPS (web pages), FTP (files), SMTP (email), DNS (names → IPs), TCP (reliable delivery), IP (addressing & routing).

The layer models — OSI & TCP/IP

Why layers existSending data involves many separate jobs — transmitting signals, finding the device, checking nothing is lost, handing it to the right app. Doing all that at once is overwhelming, so networking is split into layers, each doing one job and handing off to the next.
Analogy — posting a parcelYou write the letter → address the envelope → hand it to the post office → they route it via trucks and planes → it's delivered and read. Each step only cares about its own job. That separation is exactly what layers give us.

OSI model — 7 layers (the teaching model)

7Application — the app you use (browser, email)
6Presentation — formats / encrypts the data
5Session — opens, manages, closes the conversation
4Transport — reliable delivery (TCP lives here)
3Network — IP addresses & routing (IP lives here)
2Data Link — the local hop via MAC (Ethernet)
1Physical — the actual cables, signals, radio waves
Memory trick (top→bottom)All People Seem To Need Data Processing.

TCP/IP model — 4 layers (what the internet runs on)

TCP/IP layerCovers OSI layersExamples
ApplicationSession + Presentation + ApplicationHTTP, FTP, SMTP, DNS
TransportTransportTCP
InternetNetworkIP
Network AccessData Link + PhysicalEthernet

Takeaway: OSI is the detailed textbook map; TCP/IP is the real-world map the internet uses. Same journey, different zoom.

IP addresses in depth

WHAT: An IP address is the logical address that identifies a device so data knows where to go.

A bit of binary first

Computers store everything as bits (a single 0 or 1), grouped into bigger units:

UnitEquals
1 byte8 bits
1 KB1024 bytes
1 MB1024 KB
1 GB1024 MB
1 TB1024 GB
Correction from the slidesThe deck said "8 bytes = 1 KB" — that's wrong. It's 1024 bytes = 1 KB. Only "8 bits = 1 byte" is correct.

Two versions of IP

IPv4 — a 32-bit address, four numbers 0–255 with dots, e.g. 192.168.1.10. Each part is an octet. About 4.3 billion addresses — nearly exhausted. IPv6 — a 128-bit address created to fix that shortage.

Special addresses

127.0.0.1 — the loopback / localhost; always points back to your own machine (used for testing). 0.0.0.0 — "not connected."

Correction from the slidesThe deck wrote loopback as 127.0.01. The correct form has four parts: 127.0.0.1.

Private vs public IP

Private IP works only inside your local network (e.g. 192.168.x.x), handed out by your router. Public IP is reachable over the internet, assigned to your router by your ISP.

AnalogyYour public IP is the building's street address couriers use; private IPs are the internal room numbers. The router is the front desk translating between them — this translation is called NAT.
7

Subnetting & CIDR

WHAT: Subnetting divides one big IP network into smaller pieces called subnets.

WhyA giant flat network is inefficient and hard to secure. Splitting it keeps traffic organised, faster, and easier to control access between groups.
AnalogyA company building split into departments. The building address is the network part of the IP; your desk number is the host part. Subnetting decides how many departments and how many desks each gets.

CIDR notation

An IP range written with a slash and a number: 192.168.1.0/24. The number says how many bits belong to the network part.

NotationAddresses
/24256 (common home/office subnet)
/1665,536
/8~16 million
Rule of thumbThe higher the slash number, the fewer addresses the network holds.

Cloud computing

WHAT: Getting computing resources — servers, storage, software — on demand over the internet, instead of owning the hardware.

AnalogyElectricity from the grid. You don't build a power station in your garden — you plug in and pay for what you use. The cloud is computing delivered the same way.

Deployment models — who it's for

ModelMeaning
PublicShared across many customers over the internet (AWS, Azure)
PrivateFor one organisation only
HybridA connected mix of public + private
