Shaping Real Data — Lab

Four tools and twelve coding challenges on the skill every MERN screen depends on: taking a list of records and turning it into what the page needs. The tools show you what each method really does. The challenges work like a placement coding round — and every one of them also checks that you never changed the data you were given.

Twelve coding challenges

    
Each asks for one function. The grader calls it with data and compares what it returns — what you print is ignored. Run tries the samples; Submit adds the hidden edge cases. Every test in this module also checks one more thing: that your function did not change the data it was given. A right answer that damages the input is still a wrong answer.
