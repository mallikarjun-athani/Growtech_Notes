        The rule behind it
        Four values run clockwise from the top: T, R, B, L. With three, the left copies the right. With two, each side copies its opposite. With one, everything copies it. Corners in border-radius follow the same clockwise order, starting from top-left.

        What to notice
        Padding on the parent stops the parent-child collapse but does nothing to the sibling collapse. Only display:flex with gap removes both — which is why modern layouts hardly ever use vertical margins at all.
