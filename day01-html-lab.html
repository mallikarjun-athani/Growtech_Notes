2 · The critical rendering path

The single most asked front-end interview question is "what happens between the browser getting HTML and pixels on screen?" Step through it once and the answer is theirs for good.

Press Step to walk the pipeline.
Consequence 1

display:none is not in the render tree

It exists in the DOM but never reaches layout — no space, no paint. visibility:hidden does reach layout, which is why it keeps its space.

Consequence 2

CSS blocks the first paint

No CSSOM means no render tree. A heavy stylesheet delays paint even when the HTML arrived instantly.

Consequence 3

Layout is the expensive stage

Changing width re-runs layout. Changing colour only re-runs paint. Animating transform skips both.

The rule they should memorise defer for your own code (order is guaranteed) · async for third-party like analytics (order does not matter) · never a bare script tag in the head.
